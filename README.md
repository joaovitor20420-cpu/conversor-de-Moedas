## 📱 Sobre o Projeto

O **CurrencyX** é uma aplicação web de câmbio desenvolvida com foco em alta fidelidade visual e ótima experiência do usuário (UX). Ela simula um smartphone premium em tela com acabamentos de vidro fumê (*glassmorphism*), iluminação ambiente dinâmica (*ambient mesh*) e micro-interações fluidas ao converter e trocar moedas.

---

## 🪙 Moedas Suportadas

| Moeda | Símbolo | Código | Ícone |
| :--- | :---: | :---: | :---: |
| **Real Brasileiro** *(Origem)* | R$ | BRL | 🇧🇷 Bandeira do Brasil |
| **Dólar Americano** | US$ | USD | 🇺🇸 Bandeira dos EUA |
| **Euro** | € | EUR | 🇪🇺 Bandeira da União Europeia |
| **Libra Esterlina** | £ | GBP | 🇬🇧 Bandeira do Reino Unido |
| **Bitcoin** | ₿ | BTC | 🪙 Símbolo Oficial Bitcoin |

---

## ✨ Funcionalidades

- [x] **Conversão Instantânea:** Calcula a conversão de Real (BRL) para Dólar, Euro, Libra ou Bitcoin com um clique.
- [x] **Troca Dinâmica de Ativos:** Ao selecionar uma nova moeda no menu, o ícone vetorial e o nome da moeda são atualizados instantaneamente.
- [x] **Formatação Internacional:** Valores monetários são formatados conforme as regras e padrões internacionais (`Intl.NumberFormat`).
- [x] **Interface Mobile Mockup:** Chassi estilizado com notch/ilha dinâmica, moldura usinada e barra de navegação inferior.
- [x] **100% Responsivo:** Adaptável tanto para desktops quanto para dispositivos móveis reais.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível com tags semânticas e metadados.
- **CSS3 Puro (Vanilla):** Variáveis CSS, flexbox, glassmorphism, sombras volumétricas e iluminação ambiente.
- **JavaScript Moderno (ES6+):** Manipulação de DOM, formatação monetária com `Intl.NumberFormat` e ouvintes de eventos (`click`, `change`).
- **SVG Vetorial:** Ícones próprios e otimizados em 72x72 para máxima nitidez visual.

## 🚀 Como Executar Localmente

   ```bash

   ```

   ```bash
   cd "Conversor de moedas"
   ```

3. **Abra no navegador:**
   - Dê um duplo clique no arquivo `index.html`, ou
   - Use uma extensão como o **Live Server** no VS Code.
